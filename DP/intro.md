Dynamic Programming

See how to check if the problem to solved by DP or recursion

Recursion is parent of DP

Indentification :- 
First while solving if we have a choice like choosing the element from the array or subarray or both
in that choice we will try to solve the problem using DP and recursion

Second if we have question like choose maximum or minimum or sum or product or any kind of calculation 

Method to solve :-
Try to write the recursive solution for the problem 
Then memoise
Then top down approach

Recursion=Compute + Storage

If a same question is called twice means overlap happened we try to store the solution in first call then memoise then closing our eyes only we can say that this problems involve DP
